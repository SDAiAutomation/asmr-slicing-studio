# ASMR Slicing Studio

Vidéos ASMR verticales de découpe 3D **progressive** (Blender + FFmpeg), rendues sur GitHub Actions.

**Lancer une vidéo :** onglet *Actions* → *Render ASMR video* → *Run workflow* (objet, nombre de morceaux, qualité).
Le MP4, les previews et les rapports sont dans les *Artifacts* du run.
